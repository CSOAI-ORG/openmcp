What it is

meok-cross-post (openMCP) scores a flagship MCP server repo 0–100 against a 5-category rubric, then pushes its metadata to the directories that have public APIs (Smithery, the MCP Registry) and prints a clean, exact manual checklist for the ones that don't (Docker MCP Catalog, Glama, MCPize, PulseMCP). Discoverability that's tedious once and impossible at scale, done in one shot.

The 100-point rubric

CategoryPtsWhat it checks
A. Package installability25pyproject.toml, hatchling backend, only-include, mcp>=1.0.0, scripts entry, wheel builds
B. Server correctness25server.py imports, mcp object declared, ≥3 tools, all tools docstringed, auth_middleware.py, real test file
C. Discovery & directories25smithery.yaml (declarative), server.json, server-card.json, glama.json, package.json
D. Distribution & ops15Dockerfile.glama, mcp-wrapper.py, GHCR image public, listed on Smithery, listed on MCP Registry
E. CI/CD & docs10test.yml + ci.yml + publish workflow, README install/features/license, SECURITY.md

Merge gate: total ≥ 80 AND every per-category minimum satisfied. Empty shells score ≤ 4/100 → BLOCK.

Install

pip install meok-cross-post
# or run without installing:
uvx --from meok-cross-post meok-cross-post audit /path/to/flagship

Usage

meok-cross-post audit /path/to/flagship                 # markdown scorecard (local-only)
meok-cross-post audit /path/to/flagship --format json   # JSON for CI / dashboards
meok-cross-post audit /path/to/flagship --network       # + GHCR / Smithery / MCP Registry probes
meok-cross-post cross-post /path/to/flagship            # push to Smithery + MCP Registry
meok-cross-post checklist /path/to/flagship             # manual-submission checklist
meok-cross-post all /path/to/flagship                   # audit -> cross-post -> checklist

MCP server

openMCP also ships a thin MCP shim over the streamable-http transport (default http://localhost:8000/mcp), so any MCP-aware agent can drive the same functionality.

openmcp                 # starts the shim on $PORT (default 8000)

FAQ

What is openMCP / meok-cross-post?

A Python CLI (with an MCP shim) that audits a Model Context Protocol server against a 100-point rubric and cross-posts it to Smithery, Glama, MCPize, PulseMCP, the MCP Registry, and the Docker MCP Catalog. Apache-2.0, Python 3.10+.

How do I list an MCP server on Smithery?

Run meok-cross-post cross-post /path/to/repo; openMCP PUTs your display card to Smithery via its public API (and to the MCP Registry). For directories without an API it prints the exact submission URL.

Which directories does it post to automatically?

Two — Smithery and the MCP Registry — because those expose public APIs. Docker MCP Catalog, Glama, MCPize, and PulseMCP have no public API, so openMCP prints an exact manual checklist (and a ready-to-PR Docker YAML) instead of faking a submission.

Does the audit make network calls?

No, by default. audit is local-only so it is safe on the PR hot path. Add --network to enable three probes (GHCR, Smithery, MCP Registry), used in the monthly cron.
